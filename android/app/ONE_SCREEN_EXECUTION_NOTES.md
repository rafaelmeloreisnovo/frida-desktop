# One-screen execution notes

- The operator panel is intentionally a thin Java/DEX layer.
- Runtime authority stays in the native ELF via JNI.
- Frida Gadget remains available for external/on-device instrumentation, but ordinary metric collection is local in the Activity.
- No synthetic observation is generated by the UI.
- Numeric observation fields are parsed fail-closed; malformed or incomplete input is rejected without touching RFL state.
- `Executar diagnóstico completo` is read-mostly: it refreshes native state and only flushes RFL when the current logical mode is not OFF.
- Existing advanced Learning spinner/reset/flush controls remain available on the same Activity for expert use; they are not required for the basic metrics path.
